# 方法学蓝图

## 研究范式

**选择：实证主义为主、设计科学为辅的定量研究。**

论文首先构建一个可运行的设计意图恢复方法，再通过受控对比实验验证它是否比基线
更准确。模型、IR 和约束解码器属于设计科学产物；当前定量证据由来源分层的参考
数据支持，不能把 AI Silver 上的一致性扩张解释为相对人类判断的准确率。

## 研究方法

**类型：定量比较实验。**

具体方法包括：

1. 构建大规模弱标注训练集；
2. 整理 10 页单人 AI 辅助定稿的 Human Gold，并生成 50 页来源可追溯的 AI Silver；
3. 训练双流设计意图恢复模型；
4. 与 DOM 直映射、启发式压缩、代码单模态、视觉单模态和无对齐双流模型比较；
5. 通过消融实验分析各模块贡献；
6. 通过重渲染和自动编辑任务验证结构改善没有破坏视觉与编辑行为。

论文不把当前 100 个样本上的训练结果作为最终证据。现有结果仅用于证明训练链路可运行。

## 数据策略

### 数据层级

| 数据层 | 当前规模 | 用途 | 标签来源 |
| --- | ---: | --- | --- |
| `D_weak_pilot` | 492 页 | 弱监督预训练与工程验证 | 可解释规则教师 |
| `D_human_gold` | 10 页 | 探索性人类参考 | 单名人工标注者以人工底稿结合 AI 差异提示后定稿 |
| `D_ai_silver` | 50 页 | 来源感知训练、开发与 AI 参考一致性评测 | 截图 + PageGraph 的多阶段 AI 流程 |

Reference v1 固定为 train/validation/test 30/10/20，其中 Human Gold 为 7/1/2，
AI Silver 为 23/9/18。固定规则曾在 8 页 train/validation Human Gold 上做诊断性
回放，但这些结果没有用于选择或修改 `0.75/0.85` 阈值；2 页 test 仅能称为“未参与
该回放”，不能声称整个开发过程完全盲法。当前设计不能支持稳定的人类准确率估计或
人类标注者间信度；未来若补充真人标签，应新增独立测试层，不覆盖当前 provenance。

### 页面采样

- 按页面用途分层：内容页、电商、表单、仪表盘、营销页；
- 控制 DOM 节点数、视觉密度和布局复杂度；
- 对 HTML 结构指纹和近似截图做去重；
- 同一站点、同一模板或高相似结构不得跨训练、验证和测试集；
- 主实验冻结前补齐数据集版本、许可、获取时间和逐页可追踪 ID；当前 Reference v1
  尚未完整保存这些治理字段，不把它们写成已完成事项。

### 页面代码表示

`P` 定义为 Page Implementation Graph：

```text
P = (V, E_dom, E_spatial, X_text, X_struct, X_geom, X_style)
```

- `V`：可见页面节点；
- `E_dom`：过滤后的 DOM 父子边；
- `E_spatial`：包含、邻接、对齐和重复关系；
- `X_text`：标签、直接文本和有限属性；
- `X_struct`：深度、兄弟序号、子节点数；
- `X_geom`：归一化 bbox、面积和宽高比；
- `X_style`：计算样式的结构化编码。

计算样式可以作为输入。未来 Human Gold 应由具备已记录资历的人员判断设计意图；AI Silver 则必须
披露 computed style 依赖。由输入字段直接复制得到的规则标签不能冒充人工测试真值。

## 参考标注协议

每个页面标注以下对象：

1. **Atomic Element**：需要在设计工具中独立选择和编辑的文本、图像、图标、形状、输入控件；
2. **Component Group**：应共同移动、复用或布局的元素集合；
3. **Design Tree**：组与元素之间的直接父子关系；
4. **Layout Constraint**：布局模式、gap、padding、主轴/交叉轴对齐和尺寸约束；
5. **Style Token**：颜色、文本、圆角、间距的同 token 引用关系。

当前 Human Gold 由同一名人工标注者先完成底稿，再从该人工底稿初始化审核草稿，
结合 AI 差异提示后定稿。该流程是单人 AI 辅助复核，不是独立 adjudication；
`reviewer_independent_of_base_annotator=false`。现有记录未保存其设计资历、与论文
作者的关系或利益冲突状态，故只能作为探索性人类参考，不能暗示外部专家验证。
AI Silver 的目标页不读取人工标签，但读取截图、PageGraph、两条结构候选和
computed style；所有输入及输出均保存 SHA-256。两层标签必须分别报告。

当前 10 页 Human Gold 的 token 均为空，但没有 token 人工复核记录，因而既不能
解释为“无 token”的显式负例，也不能计算 Human Gold token F1。AI Silver token
使用“至少 3 个成员、分类型截断、每页最多 12 个”的 capped computed-style proxy；
它与人工协议“至少 2 个成员、无上限”的 truth space 不等价，不做跨 tier 混合训练
或直接指标比较。未来补人工 token 前必须先统一候选与截断契约。

若未来取得两个独立真人标注，才使用以下一致性指标：

- 原子元素：匹配后 F1；
- 分组与 token：B-cubed F1；
- 设计树：父子边 F1；
- 布局分类：Cohen's kappa；
- 连续布局值：ICC 或平均绝对差。

当前 10 页只有一名人工标注者完成主标注与 AI 辅助定稿，AI 代理不是第二位真人；
50 页 AI Silver 的同模型家族多阶段角色也不是独立标注员。因此当前不报告人工
标注者间一致性。完整披露见 `18_ai_multiview_silver_protocol.md`。

## 模型与训练策略

### 训练阶段

1. **弱监督预训练**：在 `D_weak` 上学习节点对齐、元素保留、分组、布局、token 和设计树；
2. **来源感知微调**：分别实验弱标签、AI Silver、混合 Reference；AI Silver 需
   保留来源并建议降权；
3. **冻结分层评测**：validation 选择阈值后在 test 一次性生成结果，分别报告
   `n=18` AI Silver 与 `n=2` Human Gold，混合总分只作补充。

### 多任务目标

```text
L = lambda_atomic * L_atomic
  + lambda_group  * L_group
  + lambda_role   * L_role
  + lambda_layout * L_layout
  + lambda_token  * L_token
  + lambda_tree   * L_tree
  + lambda_align  * L_align
```

所有损失均使用有效节点 mask。弱标签额外携带 `confidence`，低置信标签降低权重或不参与损失。损失权重只在验证集上选择并冻结。

## 基线与消融

### 基线

| 编号 | 方法 | 目的 |
| --- | --- | --- |
| B0 | DOM 直接映射 | 衡量不做意图恢复的下界 |
| B1 | 规则压缩与布局推断 | 强启发式基线 |
| B2 | 现有节点级 FigmaGenerationModel | 与旧课题方案连续对比 |
| B3 | 代码单模态模型 | 检验视觉流的边际贡献 |
| B4 | 视觉单模态模型 | 检验代码表示的边际贡献 |
| B5 | 双流但无显式对齐监督 | 检验对齐损失贡献 |
| M | 完整模型 | 主方法 |

为保证公平，B3、B4、B5 和 M 使用相同候选节点与 bbox。视觉单模态仍可使用候选框作为定位信息，但不能访问标签、文本或计算样式。

### 必做消融

- 去掉视觉流；
- 去掉结构化样式特征；
- 去掉显式对齐监督；
- 去掉空间关系边；
- 去掉约束解码器，仅按最大概率独立输出；
- 只用弱监督，不加入 Reference 微调；
- 去掉 AI Silver，只用现有 Human Gold 的探索性微调；
- 改变弱监督数据规模，绘制数据规模曲线。

## 评测框架

### 主指标

| 维度 | 主指标 | 说明 |
| --- | --- | --- |
| 原子元素 | Leaf Preservation F1 | 防止靠删节点提升简洁性 |
| 组件分组 | B-cubed F1、Group Match F1 | 同时评价成员级与完整组级质量 |
| 设计树 | Parent Edge F1、Normalized TED | 评价直接父子边和整体结构 |
| 布局 | Macro-F1、Gap/Padding MAE | 分类与连续属性分开报告 |
| 样式 token | Token B-cubed F1、Purity、Coverage | 仅 AI Silver computed-style proxy 工程诊断；Human Gold 为 N/A |
| 视觉约束 | SSIM、位置/颜色误差 | 重渲染后计算 |

### 诊断指标

- Layer Compression Ratio；
- Redundant Wrapper Ratio；
- Semantic Naming Rate；
- 节点-patch 对齐 AUROC/AUPRC；
- 不同页面复杂度和 DOM-视觉冲突程度下的分层结果。

压缩率和 wrapper 比例不能作为独立成功指标，因为删除全部节点也能获得很高压缩率。
AI token Coverage 必须与 Purity 或 token F1 同时报告，但这些数值仍只衡量与自动
聚类规则的一致性，不能证明人类复用意图。

### 自动编辑任务

对 IR 执行确定性编辑并检查行为：

1. 调整容器宽度，检测子节点重叠、越界和对齐保持；
2. 修改一个颜色 token，检测所有引用是否一致更新；
3. 调整组件间 gap，检测顺序和间距是否保持。

该测试提供面向“二次编辑”的行为证据，不依赖主观用户评分。

## 统计分析

- 每个学习方法使用 3 个随机种子；
- AI Silver test `n=18` 单独报告均值、标准差、效应量和页面级 bootstrap 95% CI，
  并明确其样本量小、推断功效低；配对检验只作探索性分析；
- Human Gold test `n=2` 仅逐页描述，不计算 CI、`p` 值或稳定的总体均值；
- 禁止对 20 页混合 test 做单一 bootstrap、显著性检验或人工准确率推断；
- 预注册主指标、非劣界限、阈值选择规则和排除标准；
- 多重比较使用 Holm 校正；
- 失败页面不静默删除，按预注册规则计入失败率。

## 有效性控制

| 威胁 | 控制策略 |
| --- | --- |
| 标签泄漏 | 标签来源分层；8 页仅做固定规则诊断回放，2 页未参与回放但开发者盲法不保证；不得把混合总分解释为人工准确率 |
| 模板泄漏 | 站点、模板和结构指纹分组切分 |
| 伪标签确认偏差 | AI Silver 来源感知与降权；单独报告仅弱监督、无 Silver 和混合 Reference 模型 |
| 候选节点偏差 | 报告 candidate oracle recall，区分候选生成与意图解码误差 |
| 指标投机 | 主指标成组报告；压缩率与 coverage 仅作诊断 |
| 训练不稳定 | 3 seeds、固定配置、保存数据清单和代码版本 |
| 外部有效性不足 | 页面类型分层报告，明确只覆盖桌面首屏静态页面 |
| 视觉模型贡献不显著 | 预先接受零结果，分析贡献发生的页面子集 |

## 伦理与数据治理

- 不主动收集登录后页面、个人账户页面或包含敏感个人信息的页面；
- 对公开网页中的邮箱、电话和账号标识做检测与脱敏；
- 保存来源与许可记录，不把无法确认授权的数据公开再分发；
- 论文中披露 AI 参与了方案讨论、代码生成和文字整理，并由作者负责验证；
- 当前人员角色、与作者关系及公开姓名同意状态尚未归档，不能在此无条件断言无需
  伦理审查；论文提交或数据发布前须按所在机构规则确认其属于研究团队成员、受试者
  或外部服务人员，并补充相应同意、利益冲突和匿名化记录；
- 若后续加入设计师评分实验，必须在执行前补充伦理审查、知情同意和匿名化方案。

## 预注册与报告

- 建议在主实验前将实验协议注册到 OSF；
- 当前工作属于机器学习系统比较实验，无直接对应的 EQUATOR 医学报告规范；
- 采用可复现机器学习报告清单：数据版本、切分、超参数、随机种子、计算资源、失败案例和负结果全部披露。

## 设计冻结决策

**当前决策：`reference_v1_frozen_with_major_validity_limitations`。**

冻结前必须完成：

1. 所有训练与评测代码消费 `reference_tier` 并输出按来源分层的指标；
2. 报告 AI Silver 同源偏差、Human Gold `n=2`、固定规则诊断回放及开发者可能接触 Human Gold；
3. 完成三随机种子、基线和消融实验，不把 smoke 结果写入结论；
4. 完成外部文献检索后重新评估 Novel 得分与基线选择。
