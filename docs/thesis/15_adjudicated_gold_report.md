# 10 页单人 AI 辅助定稿 Human Gold 报告

## 1. 数据状态

- 单名人工标注者底稿：10/10 完成；
- 独立 AI 代理候选：10/10 完成；
- 同一人工标注者提交审核声明并定稿：10/10 完成；
- 最终 `gold_intent.json`：10/10 导出，结构校验错误 0；
- 公开审核编号：`human_reviewer_01`；每页均记录审核时间与非空说明；
- 原始人工与 AI 输入 SHA-256 均未发生变化。

该过程属于“AI 独立生成候选 + 同一人工标注者以人工底稿初始化后复核定稿”，
不能表述为双人标注、独立裁决或标注者间一致性实验。现有记录未归档该人员的
设计资历、与论文作者关系、利益冲突或公开姓名同意状态。

## 2. 仲裁结果

最终金标准共包含：

| 对象 | 数量 |
| --- | ---: |
| 原子元素 | 320 |
| 语义分组 | 107 |
| 布局约束 | 107 |
| 父子边 | 427 |

6 页最终内容与人工底稿完全一致；`0001`、`0020`、`0601`、`0860` 共 4 页
发生了实际修改。没有任何一页完整复制 AI 结果，说明最终标签不是自动替换所得。

## 3. 描述性比较

| 指标 | 人工主标注 → Gold | AI 代理 → Gold |
| --- | ---: | ---: |
| 原子元素 F1 | 0.9795 | 0.7905 |
| 分组 B-cubed F1 | 0.9834 | 0.7999 |
| 父子关系 F1 | 0.9702 | 0.4254 |
| 布局 Cohen's kappa | 1.0000 | 0.8202 |
| 树归一化编辑距离 | 0.0474 | 0.6563 |

这些数值只描述人工、AI 与最终定稿之间的距离，不能作为双人信度，也不能证明
AI 达到专业设计师水平。由于定稿草稿由人工底稿初始化且由同一人复核，Gold 更
接近人工底稿在流程上部分预置；不能仅凭该距离断言 AI 的结构能力更差。父子层级
差异可作为诊断线索，但需独立真人参考才能支持准确性结论。

## 4. 研究限制

10 页 Gold 均未标注正例样式 Token。因此：

- 该 Pilot 可以验证元素、分组、父子层级和布局任务；
- `token_bcubed_f1=1.0` 的人工到 Gold 结果仅表示双方都为空，不能解释为高质量；
- 当前数据不能支撑 Token 恢复模型的正例学习和效果结论；
- 正式实验前应新增包含颜色、字号、圆角或间距联动关系的 Token 标注样本，或将
  Token 任务明确降级为探索性分析。

此外，7/10 审核说明仅记录“以人工为准”一类简短摘要，能够证明审核声明已提交并
存在最终文件，不能证明每条差异均有可审计决策理由。后续扩大样本时，应要求审核
说明至少记录主要分歧类型与采用依据。
