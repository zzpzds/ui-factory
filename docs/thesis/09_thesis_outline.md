# 论文结构与证据地图

## 暂定题目

《基于网页图像与源码的可编辑设计意图恢复方法研究》

正式送审时可沿用开题题目《基于网页图像与源码的设计稿生成方法研究》，并在摘要与第一章明确“生成”的核心是可编辑设计意图恢复。

## 摘要

按“问题、方法、数据、结果、贡献、限制”六句群组织。结果段在主实验完成前保持占位，禁止使用 smoke 指标。

## 第一章 绪论

1. 研究背景：网页实现数据与设计训练数据之间的结构差异；
2. 问题定义：格式转换不等于可编辑设计恢复；
3. 研究问题与假设：RQ、SQ1-SQ3、H1-H4；
4. 研究内容：PageGraph、Design Intent IR、双流模型、约束求解；
5. 贡献边界：不声称恢复设计师唯一主观意图；
6. 论文结构。

所需证据：10 页 Human Gold 中 DOM 树与设计树差异的探索性统计、AI Silver 的
来源与局限、现有方法能力边界。

## 第二章 相关工作

1. Screenshot-to-code 与 GUI 理解；
2. HTML-to-design/Figma 转换；
3. 布局生成与结构化解码；
4. 多模态对齐与弱监督学习；
5. UI 数据集与可编辑性评价；
6. 研究空白与本文定位。

写作约束：分开陈述已核验事实与本文推断；以 `08_verified_literature_map.md` 为起点继续系统检索。

## 第三章 问题建模与数据构建

1. 任务形式化；
2. Page Implementation Graph；
3. Design Intent IR；
4. 弱标签教师；
5. Human Gold 与 AI Silver 双层参考数据构建；
6. 分组切分、近重复检测与数据治理；
7. 质量控制、来源审计与有效性威胁。

所需表格：字段定义、按标签来源的数据规模、页面类型、失败率和视觉风险。当前没有
两名独立真人标注，不设置“人工标注者间一致性”结果表。

## 第四章 双流设计意图恢复方法

1. 总体架构；
2. 视觉编码器；
3. 页面图编码器；
4. bbox 引导跨模态融合；
5. Atomic/Group/Layout/Token/Tree 多任务解码；
6. 置信度加权损失；
7. 约束求解器；
8. Figma-like JSON 与可编辑 HTML 导出。

所需图：系统总图、IR 示例、融合模块、约束解码流程。

## 第五章 实验设计与结果

1. 实验设置与复现环境；
2. 比较方法；
3. 主结果；
4. 消融实验；
5. 数据规模、AI Silver 权重与无 Silver 消融；
6. DOM-视觉冲突子集分析；
7. 可编辑行为与重渲染分析；
8. 统计检验；
9. 失败案例。

主结果表不得合成单一总分。AI Silver `n=18` 单独报告页面级均值、标明低功效的
95% CI、三随机种子均值与标准差；Human Gold `n=2` 只逐页描述，不计算 CI 或
`p` 值。禁止对来源混合的 20 页 test 做单一显著性检验。

## 第六章 讨论

1. 视觉模态是否产生独立贡献；
2. 弱监督偏差与标签泄漏；
3. 可编辑性定义的有效性；
4. 对网页设计训练数据构造的意义；
5. 内部、外部、构念和结论效度威胁；
6. 隐私、许可与工程限制。

## 第七章 总结与展望

只总结被实验支持的结论。未来工作包括响应式、多状态交互、真实 Figma 插件和跨页面组件系统，不把未实现功能写成当前贡献。
