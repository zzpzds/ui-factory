# 研究问题简报

## 课题定位

论文题目保持为《基于网页图像与源码的设计稿生成方法研究》。

本文不把任务定义为 HTML/CSS 到 Figma JSON 的格式转换，而将其定义为：

> 给定网页截图与页面代码表示，恢复被前端实现结构掩盖的可编辑设计意图，并生成具有合理组件聚合、设计图层树、布局约束和复用样式的设计稿中间表示。

网页代码是实现证据，不是设计真值。模型需要从 DOM、计算样式、几何关系和最终视觉结果中推断更高层的设计结构。

## 主研究问题

**RQ：融合网页截图与页面代码表示的模型，能否相较于单模态模型和启发式转换方法，更准确地恢复网页的可编辑设计意图？**

“可编辑设计意图”在本文中被操作化为以下四类可测对象：

1. 原子设计元素及其保留关系；
2. 组件聚合和设计图层树；
3. AutoLayout-like 布局约束；
4. 可复用样式 token 及其引用关系。

视觉保真度是约束指标，不作为可编辑性的替代指标。

## 子研究问题

### SQ1：结构恢复

双流模型能否比 DOM 直接映射、规则压缩和单模态模型更准确地恢复原子元素、组件分组与设计树父子关系？

继承范围：桌面端静态网页、首屏可见区域、统一 Design Intent IR、相同候选节点集合。

### SQ2：约束与样式恢复

双流模型能否更准确地恢复布局模式、间距、内边距、对齐方式以及样式 token 的归并关系？

继承范围：与主问题一致；样式 token 仅包括颜色、文本、圆角和间距，不评价完整设计系统语义。

### SQ3：多模态贡献

视觉流、代码流、显式节点与视觉区域对齐以及约束解码分别对恢复质量和视觉保真度产生何种影响？

继承范围：与主问题一致；通过受控消融回答，不把训练数据规模变化混入模块消融。

## 研究假设

- **H1**：完整双流模型在金标准测试集上的组件分组 F1 和父子边 F1 显著优于最强启发式基线。
- **H2**：完整双流模型在布局约束与 token assignment 指标上显著优于代码单模态模型，说明模型并非只复制计算样式。
- **H3**：显式视觉-代码对齐在 DOM 结构与视觉结构不一致的页面子集上带来更大增益。
- **H4**：结构压缩和可编辑性提升不会造成不可接受的视觉退化；重渲染 SSIM 的平均下降不超过预注册阈值。

H2 是风险最高的假设。若代码单模态已经达到相同水平，论文应如实得出“视觉模态对该子任务贡献有限”，而不是通过改变指标掩盖结果。

## 范围边界

### 纳入范围

- 输入为网页截图 `I` 和页面代码表示 `P`；
- `P` 包含可见 DOM 节点、文本、属性、父子关系、渲染几何和计算样式；
- 桌面端固定视口，首屏静态渲染结果；
- 输出为可验证的 Design Intent IR，再确定性转换为 Editable Figma JSON；
- 研究组件聚合、设计树、布局约束、样式 token 和视觉保真度；
- 使用大规模弱标注数据训练，并使用独立人工标注数据验证。

### 排除范围

- 不恢复交互流程、动画、状态机和跨页面导航；
- 不处理完整响应式断点行为，只处理单一视口下的约束近似；
- 不声称生成结果与原设计师的主观意图完全等价；
- 不覆盖 Figma 插件 API 的全部字段；
- 不把隐藏节点、不可见 DOM、脚本业务逻辑作为设计对象；
- 不以自动构造的弱标签作为最终测试真值；
- 不把压缩率、token coverage 或视觉相似度中的任何单项称为“可编辑性”。

## 成功判据

主结论成立至少需要同时满足：

1. 在独立金标准测试集上，完整模型至少在结构、布局或 token 三个维度中的两个显著优于最强非学习基线；
2. 完整模型相对代码单模态模型存在可重复增益，或能明确界定视觉模态只对哪些页面有效；
3. 结构改善不是通过丢弃关键内容获得，Leaf Preservation F1 不降低；
4. 视觉保真度保持在预注册的非劣界限内；
5. 结果来自页面级、模板隔离的数据划分，并报告三个随机种子的均值、标准差和置信区间。
