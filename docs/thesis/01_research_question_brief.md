# 研究问题简报

## 课题定位

论文题目保持为《基于网页图像与源码的设计稿生成方法研究》。

本文不把任务定义为 HTML/CSS 到 Figma JSON 的格式转换，而将其定义为：

> 给定网页截图与页面代码表示，恢复被前端实现结构掩盖的可编辑设计意图，并生成具有合理组件聚合、设计图层树、布局约束和复用样式的设计稿中间表示。

网页代码是实现证据，不是设计真值。模型需要从 DOM、计算样式、几何关系和最终视觉结果中推断更高层的设计结构。

## 主研究问题

**RQ：融合网页截图与页面代码表示的模型，能否相较于单模态模型和启发式转换方法，更准确地恢复网页的可编辑设计意图？**

这是论文希望回答的强研究问题，但当前 Reference v1 不能提供充分的人类真值证据。
50 页 AI Silver 只能支持可行性、系统比较和代理标签一致性结论；2 页 Human Gold
test 只能逐页描述。若不补充独立真人测试集，论文结论必须收缩为 feasibility study，
不得声称已经验证“相对人类设计意图更准确”。

“可编辑设计意图”在本文中被操作化为以下四类可测对象：

1. 原子设计元素及其保留关系；
2. 组件聚合和设计图层树；
3. AutoLayout-like 布局约束；
4. 可复用样式 token 及其引用关系。

视觉保真度是约束指标，不作为可编辑性的替代指标。

## 子研究问题

### SQ1：结构恢复

双流模型能否比 DOM 直接映射、规则压缩和单模态模型更准确地恢复原子元素、组件分组与设计树父子关系？

继承范围：桌面端静态网页、首屏可见区域、统一 Design Intent IR、相同候选节点集合。

### SQ2：约束与样式恢复

双流模型能否更准确地恢复布局模式、间距、内边距和对齐方式？在工程诊断层面，
它能否复现 capped computed-style token proxy 的归并关系？

继承范围：与主问题一致。当前 10 页 Human Gold 没有可审计的 token 正例或显式
负例，AI Silver token 又直接来自 computed style 自动聚类，因此 token 不进入人类
设计意图的核心准确性结论。

### SQ3：多模态贡献

视觉流、代码流、显式节点与视觉区域对齐以及约束解码分别对恢复质量和视觉保真度产生何种影响？

继承范围：与主问题一致；通过受控消融回答，不把训练数据规模变化混入模块消融。

## 研究假设

- **H1-P**：完整双流模型在冻结 AI Silver test 上的组件分组 F1 和父子边 F1
  优于最强启发式基线；该假设只检验与 AI 结构代理的一致性。
- **H1-H**：相对人类设计判断的结构增益必须由新增的独立真人测试集检验；现有
  2 页 Human Gold 只做案例级方向观察，不进行假设检验。
- **H2a**：完整双流模型在布局约束指标上优于代码单模态模型；在 AI Silver 上
  仍只解释为代理一致性。
- **H2b**：模型与 capped computed-style token proxy 的 assignment 一致性优于
  基线。该工程诊断不能证明恢复了人类复用意图，也不能排除 computed-style shortcut。
- **H3**：显式视觉-代码对齐在 DOM 结构与视觉结构不一致的页面子集上带来更大增益。
- **H4**：结构压缩和可编辑性提升不会造成不可接受的视觉退化；重渲染 SSIM 的平均下降不超过预注册阈值。

H2a 是风险较高的假设。若代码单模态已经达到相同水平，论文应如实得出“视觉模态
对该子任务贡献有限”，而不是通过改变指标掩盖结果。H2b 不参与这一构念结论。

## 范围边界

### 纳入范围

- 输入为网页截图 `I` 和页面代码表示 `P`；
- `P` 包含可见 DOM 节点、文本、属性、父子关系、渲染几何和计算样式；
- 桌面端固定视口，首屏静态渲染结果；
- 输出为可验证的 Design Intent IR，再确定性转换为 Editable Figma JSON；
- 研究组件聚合、设计树、布局约束、样式 token 和视觉保真度；
- 使用弱标注和来源感知 Reference 数据训练；AI Silver 与 Human Gold 分层验证。

### 排除范围

- 不恢复交互流程、动画、状态机和跨页面导航；
- 不处理完整响应式断点行为，只处理单一视口下的约束近似；
- 不声称生成结果与原设计师的主观意图完全等价；
- 不覆盖 Figma 插件 API 的全部字段；
- 不把隐藏节点、不可见 DOM、脚本业务逻辑作为设计对象；
- 不把规则弱标签或 AI Silver 冒充人工测试真值；
- 不把压缩率、token coverage 或视觉相似度中的任何单项称为“可编辑性”。

## 当前工程与代理成功判据

当前实验阶段判定系统可行至少需要同时满足：

1. 在冻结 AI Silver test 上，完整模型在至少一个结构或布局主指标上优于最强
   非学习基线；该结果只解释为对 AI 参考标签的一致性；
2. 完整模型相对代码单模态模型在结构或布局上存在可重复增益；AI token 结果只
   作为 computed-style proxy 诊断，不能用于排除 shortcut；
3. 结构改善不是通过丢弃关键内容获得，Leaf Preservation F1 不降低；
4. 视觉保真度保持在预注册的非劣界限内；
5. 结果来自页面级、模板隔离的数据划分；AI Silver `n=18` 单独报告三随机种子、
   效应量和标明低功效的区间估计，Human Gold `n=2` 只逐页报告。

不得对 20 页混合 test 做单一显著性检验。即使满足以上判据，也只能得出工程可行性
和代理标签一致性结论；相对人类设计意图的准确性主张保持未验证。这一限制必须进入
摘要、讨论和结论，而不能只放在附录。
